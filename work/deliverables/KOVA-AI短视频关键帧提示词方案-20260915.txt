# KOVA 运动相机｜AI宣传短视频关键帧提示词方案

日期：2026-09-15
交付范围：AI短视频策划、关键帧提示词、镜头逻辑与一致性约束。每条建议 3—5 秒；本次只制作提示词，不生成视频、不修改项目代码和原文件。
最高优先级参考：本轮用户提供的三张 KOVA 产品母版图。任何旧文字与母版冲突时，以母版图为准。

## 1. 数量与选择结论

本轮建议制作 **8 条短片**。原因是 8 条可以在不重复场景的前提下覆盖：产品定型、前屏自拍、背屏回看、骑行安装、水边耐候、岩地耐用、湿手三键操作、工程结构解释。每条控制在 3—5 秒，适合详情页短循环、社媒竖版切片或作品集动态图，不把多个卖点硬塞进一个长镜头。

## 2. 全视频统一母版约束

- 产品永远是同一台 KOVA：深石墨灰微砂横向软方形机身；正面左侧近方形前屏、右侧大型纯黑圆镜头、左下 KOVA 字标；背面大面积横向屏；右侧高窄齐平仓盖。
- 顶部必须始终是 **三枚独立低矮扁平按键**。以背面视图为唯一方向基准，从右向左依次为：快门键、功能键、纹理控制键。快门键固定在背面视图顶部最右侧第一枚；最左侧第三枚为带细密纹理的控制键。正面视图只允许因观察方向产生左右视觉反转，真实物理顺序不得改变。旧文字中的单按键版本不得进入任何关键帧。
- 关键帧之间禁止产品“融化变形”：镜头直径、前屏位置、机身厚度、三键数量、仓盖轮廓和Logo位置必须稳定。
- 不用夸张广角把机身拉成梯形；运动镜头尽量保持 35—85mm 等效的自然透视。
- 不生成未经提供的 4K/8K、FPS、IP 等级、防水深度、温度、耐摔高度、重量、续航数字。
- 视频内文字建议后期叠加。AI关键帧本身优先无文字，避免短片内出现乱码；下文提供“后期字幕建议”供剪辑使用。

## 3. 真实物理逻辑

1. 自拍：镜头 + 前屏朝人物，背屏背向人物。
2. 回看：背屏朝人物，镜头 + 前屏朝反方向。
3. 头盔／船头：必须有真实快拆底座、连接件和受力关系。
4. 水边：允许浪花和水滴，不做深水长期浸泡或高压水柱。
5. 跌落：只表现低高度滑落到碎石面，产品保持完整，不做灾难性撞击。
6. 工程拆解：零件沿真实装配方向分离，不能把 KOVA 变成科幻机器人。

## 5. 逐条关键帧方案

### V01｜双视角产品定型｜4秒

**镜头逻辑：** 不生成任何中间产品角度。关键帧 A 与 B 使用完全相同的正面产品、机位、焦段、尺寸和构图；B 只是在 A 上增加一道大面积遮挡式光影，作为剪辑转场。关键帧 C 独立生成背面定型。成片时先播放 A 到 B 的光影遮挡，再在产品被遮住的瞬间硬切到 C，禁止让视频模型自动推算正面旋转到背面的过程。

**关键帧 A｜0.0秒**

```text
高端 KOVA 运动相机产品短片起始关键帧。严格以我上传的三张 KOVA 母版作为唯一产品参考。单台产品悬浮在浅暖灰到冷灰无缝空间，正面左前约20度三分之二视角。深石墨灰微砂横向软方形机身，左侧近方形前屏点亮高山画面，右侧大型纯黑圆镜头，左下KOVA字标，顶部三枚低矮扁平按键清楚可见，右侧齐平仓盖比例准确。85mm产品摄影，克制柔光，无文字、无参数、无额外Logo。
```

**关键帧 B｜2.0秒｜同构图遮挡转场帧**

```text
使用已连接的关键帧 A 成图作为唯一图像参考，对原画面进行最小幅度编辑。必须完整保留关键帧 A 中的同一台 KOVA：机身轮廓、正面左侧前屏、右侧大型圆镜头、KOVA 字标、顶部三枚按键、右侧齐平仓盖、圆角、厚度、悬浮高度、投影、产品大小、透视关系和所有细节均与输入图完全一致。产品继续保持正面左前约20度三分之二视角，整台产品完整留在画面内，四周留白、产品中心位置、占画比例、85mm焦段和浅暖灰到冷灰背景均不得改变。

禁止重新设计或重新绘制相机；禁止裁切、放大、推近、旋转、俯拍、改变焦段或改变产品角度；禁止变成顶部微距；禁止增删按键；禁止改变镜头尺寸、前屏比例、仓盖形状、Logo、机身厚度和圆角；禁止出现背屏、第二块屏幕、第二个镜头或第二台相机。

唯一允许发生的变化：从画面右侧进入一块虚焦的深烟灰竖向前景遮挡，像摄影棚黑旗贴近镜头缓慢扫过。遮挡覆盖画面右侧约55%，覆盖镜头和机身右半部分，但产品左侧前屏、KOVA字标和机身左侧仍能辨认；遮挡边缘带一条极窄、柔和、低亮度的冷白光线。除此之外，产品、背景、光线和阴影全部保持关键帧 A 原样。无文字、无参数、无额外Logo。
```

**关键帧 B 的生成设置：** 只连接关键帧 A 的已确认成图，不再连接任何正面母版、背面母版或其他参考图。保持与 A 完全相同的画布比例和分辨率；若工具提供参考强度、结构保持或创意强度，使用最高参考/结构保持与最低创意变化。生成结果必须先与 A 叠放检查：产品外轮廓、四角位置、镜头圆心、前屏四角、三枚按键和投影位置都应基本重合；不能重合就判定失败，不进入视频。

**关键帧 C｜4.0秒**

```text
同一台 KOVA 完成到背面右后约20度三分之二视角。大面积横向背屏点亮低饱和雪山与云海画面，黑色细边和石墨灰保护边对应母版；顶部三枚低矮按键仍可见，右侧仓盖结构准确。产品尺寸、机身厚度、圆角和颜色与起始帧完全一致。高端产品结尾静帧，无文字、无参数。
```

**运动约束：** A 到 B 只有右侧虚焦黑旗从画面外扫入，产品本体完全静止；不要添加推近、旋转或景别变化。B 到 C 不交给视频模型插值旋转，应在黑旗遮挡达到最大时通过剪辑硬切到独立生成的背面镜头，再让同样的黑旗向右退出。若只能生成一条不可剪辑的视频，则取消正背转换，只使用 A 与 B 制作正面光影展示，避免产品变形。
**后期字幕：**「同一台 KOVA，前后都清楚」左下淡入，0.8秒后出现，末帧保持。

### V02｜高山前屏自拍｜4秒

**镜头逻辑：** KOVA 在前景，人物在后景；前屏从暗到亮显示自拍构图，人物视线始终落在真实镜头。

**关键帧 A｜0.0秒**

```text
真实高山湖泊，成年东亚男女徒步者并肩站在观景点，一人伸出短小黑色无Logo自拍杆。KOVA 位于前景，严格保持三张母版外观。产品正面大型圆镜头和左侧前屏同时朝向两个人，背屏朝反方向。第三方广告机位从人物侧前方约35度观察KOVA正面，人物看向KOVA真正镜头，自然微笑。前屏刚开始点亮，低饱和自然光，无文字。
```

**关键帧 B｜2.0秒**

```text
同一场景同一人物同一KOVA。自拍杆只做轻微稳定移动，人物靠近半步。前屏已经清楚点亮，实时显示两个人与身后山湖，屏幕内容和现实左右关系基本一致。KOVA镜头仍朝人物，前屏仍与镜头同向，绝对不能出现背屏朝人物。顶部三枚按键轮廓保持稳定，无参数UI。
```

**关键帧 C｜4.0秒**

```text
同一场景收束。两人完成一次自然合影表情，前屏继续显示实时构图；第三方广告机位轻微推近KOVA，让镜头、前屏和顶部三键更清楚。产品结构完全不变，无文字、无参数、无第三方Logo。
```

**运动约束：** 人物不看广告摄影机；自拍杆不穿手；产品不能翻转180度。
**后期字幕：**「前屏取景，构图更直观」置于左上天空留白。

### V03｜雪山背屏回看｜4秒

**镜头逻辑：** 采用肩后视角，手指轻触背屏后，回放画面从静止到短暂运动；产品方向不变。

**关键帧 A｜0.0秒**

```text
冬季雪山户外环境，一双轻量运动手套自然托住KOVA。第三方广告机位在操作者右肩后方，直接看到KOVA背面大屏。KOVA背屏朝人物，正面镜头和前屏朝人物反方向。背屏显示暂停的真实滑雪画面，UI极简或无UI。产品严格对应三张母版：深石墨灰机身、大面积横向背屏、顶部三枚低矮按键、右侧齐平仓盖。无文字。
```

**关键帧 B｜2.0秒**

```text
同一机位同一KOVA。右手食指真实接触背屏，屏幕中的滑雪者从静止进入运动，允许出现一个大型低透明度播放图形随后淡去。手指不穿透玻璃，背屏不变成厚边手机。产品方向、顶部三键和侧仓盖保持不变。
```

**关键帧 C｜4.0秒**

```text
同一场景，手指离开屏幕少许，回放画面停在滑雪者切过雪坡的一帧。背屏亮度自然，雪山背景虚化，产品仍由左手稳定托住。禁止让镜头突然朝向操作者，禁止出现前屏自拍画面。无文字、无数字参数。
```

**后期字幕：**「拍完，就地回看」右上淡入。

### V04｜山地骑行头盔安装｜5秒

**镜头逻辑：** 先特写真实底座，再切到骑行跟拍；卖点来自安装与真实速度，而非特效。

**关键帧 A｜0.0秒**

```text
山地骑行短片起始关键帧。成年东亚骑手戴深灰无品牌全盔，KOVA 通过低矮黑色快拆底座真实安装在头盔顶部略靠前位置。近景侧前方拍摄，重点看清底座、卡扣、头盔曲面与KOVA之间的真实机械连接。KOVA正面镜头和前屏朝骑行前方，背屏朝后。产品必须保持母版三枚顶部按键与右侧仓盖结构，无文字。
```

**关键帧 B｜2.5秒**

```text
同一骑手已经进入林间碎石山路。第三方广告机位从侧前方低角度跟拍，骑手身体和山地车产生真实动态，KOVA与头盔连接稳定，不晃成悬浮物。镜头仍朝前，前屏同向，背屏朝后。少量尘土和林间光斑，不做夸张泥浆爆炸。
```

**关键帧 C｜5.0秒**

```text
同一骑手驶过一个自然缓坡，广告机位稍微拉远，保留头盔上KOVA可辨识轮廓与真实底座。产品形状、镜头尺寸、顶部三键数量和位置与起始帧完全一致。自然运动模糊只作用于背景和车轮，产品主体仍可识别。无文字、无参数。
```

**后期字幕：**「跟着线路，继续记录」在第1秒后从左侧淡入。

### V05｜皮划艇浪花耐候｜4秒

**镜头逻辑：** 广告摄影机始终位于皮划艇航线正前方，贴近水面的低机位，镜头朝后回拍迎面驶来的皮划艇；广告摄影机与皮划艇面对面，并以相同速度向后移动保持距离。KOVA 固定在船头纵向中轴线上，KOVA 正面镜头与前屏朝向皮划艇前进方向，也就是朝向广告摄影机；KOVA 背屏朝向后方划艇者。三个关键帧始终保持这套方向关系，只让小浪花与水滴状态发生变化。

**固定空间关系：** 画面纵向中轴从近到远依次为：广告摄影机 → KOVA 正面镜头与前屏 → 船头尖端及快拆底座 → 划艇者。皮划艇前进箭头由划艇者指向 KOVA，再指向广告摄影机。广告画面必须正面看见 KOVA 的圆形镜头和左侧前屏；绝不能看到 KOVA 背屏，绝不能让镜头朝向划艇者，绝不能把产品横装、反装或侧装。

**关键帧 A｜0.0秒**

```text
高山湖泊皮划艇场景，广告摄影机位于皮划艇航线正前方、贴近水面，面对面回拍正在朝镜头方向前进的皮划艇，并向后同步跟拍保持稳定距离。皮划艇船头从画面底部中央指向远处划艇者，船体纵向中轴清楚，不横在画面里。

同一台 KOVA 通过短小、低矮、结构真实的黑色快拆底座固定在船头纵向中轴线上，产品位于船头尖端之后且始终高于水线。KOVA 正面与皮划艇前进方向完全一致：正面右侧大型纯黑圆镜头和左侧近方形前屏同时朝向画面前方的广告摄影机；背面大屏朝向位于产品后方的划艇者，因此广告画面中完全看不到背屏。划艇者位于 KOVA 后方中央，人物尺寸小于前景产品，双手自然握桨，身体面向前进方向。

KOVA 严格保持母版：深石墨灰横向 soft-square 机身、左前屏、右大圆镜头、低调 KOVA 字标、顶部三枚低矮按键、右侧齐平仓盖。以背面视图为基准，顶部从右向左为快门键、功能键、纹理控制键，不镜像产品。机身基本干燥，湖面平稳，仅有船头切水形成的细小对称水纹。无文字、无参数、无其他品牌。
```

**关键帧 B｜2.0秒**

```text
完全延续关键帧 A 的面对面正前方跟拍机位、构图、焦段和方向关系。广告摄影机仍位于皮划艇前方并向后同步移动；皮划艇继续沿画面纵向中轴朝广告摄影机前进；KOVA 正面镜头和前屏继续朝前、朝向广告摄影机，背屏继续朝后、朝向划艇者，禁止产品旋转、镜像或改为侧面。

船头正面切过一道自然的小浪，水花从船头左右两侧向外分开，形成低矮、近似对称的 V 形水纹；只有少量水珠掠过 KOVA 机身下缘与镜头保护玻璃下部。水花不能从产品背后向前喷，不能像侧面高压水柱，不能遮住完整镜头和前屏，不能淹没产品。快拆底座与船头连接稳定，产品始终高于水线、不漂浮。划艇者仍位于产品正后方，人物与船体方向不变，光线和背景完全延续上一帧。
```

**关键帧 C｜4.0秒**

```text
继续保持与关键帧 A、B 完全相同的正前方面对面跟拍机位。皮划艇仍朝广告摄影机方向前进，船头、快拆底座、KOVA 和划艇者仍位于同一纵向轴线；KOVA 正面镜头与前屏始终朝向广告摄影机，背屏始终朝向后方划艇者且不可见。

浪花已经从船头两侧退去，同一台 KOVA 的镜头保护玻璃下缘、前屏玻璃边缘和深石墨灰微砂机身上留下少量细小自然水滴，不同材质的水滴高光应有差异。前屏可显示前进方向上的低亮度湖面与峡谷取景，不出现广告摄影机、参数或复杂 UI。产品轮廓、镜头尺寸、前屏比例、三键、右侧仓盖、底座、船头方向和划艇者位置与前两帧完全一致。无文字、无参数。
```

**V05 验收规则：** 三帧叠放时，船头尖端、底座中心、KOVA 镜头圆心和划艇者躯干中心应处于同一条纵向轴线；广告画面三帧都只能看到 KOVA 正面，不能出现背屏。若看到背屏、镜头朝向人物、船体横向运动、相机装在船尾或相机侧面对着航向，均判定为方向错误，不能进入视频。

**后期字幕：**「水边记录，保持从容」置于上方天空区域。

### V06｜碎石低落耐用｜4秒

**镜头逻辑：** 不拍高速撞击；表现“从装备袋边缘滑落—短距离落到碎石—静止完整”。

```text
禁止产品在帧间变款；禁止顶部三键变成单键、双键或四键；禁止镜头直径忽大忽小；禁止前屏变成横屏或厚边小电视；禁止背屏变成手机式厚边框；禁止KOVA字标漂移或变成随机英文；禁止侧仓盖消失；禁止机身变成GoPro公模、机甲、厚橡胶防撞壳、透明外壳；禁止人物手指穿模、自拍杆穿手、底座悬浮；禁止自拍时背屏朝人物；禁止回看时镜头朝人物；禁止夸张巨浪、高压水柱、深水长期浸泡、灾难性摔落、碎石爆炸；禁止4K/8K/FPS/ISO/IP等未经提供参数；禁止乱码、水印和第三方品牌Logo。
```

## 7. 制作顺序建议

建议先完成 V01 与 V07，验证“产品不变形 + 顶部三键稳定”后，再制作 V02、V03 两条交互逻辑片；随后做 V04、V05、V06 三条户外使用片；最后做 V08 工程拆解。任何一条出现镜头、前屏、三键、仓盖在帧间变化，都应先修母版一致性，不继续扩展动作。

## 8. 视频验收门槛

1. 每条 3—5 秒，不能超过5秒。
2. 同一条片内和不同短片之间，KOVA必须保持同一产品母版。
3. 顶部三键始终稳定，是本轮视频验收的最高优先级细节之一。
4. 自拍、回看、安装场景的镜头方向和人物视线必须符合真实物理关系。
5. 快拆底座、头盔、船头和手部接触必须真实，不悬浮、不穿模。
6. 水与跌落场景只表达可相信的户外状态，不用未经证实的性能数字或灾难性特效。
7. 技术拆解必须从完整母版产品中“解释”结构，而不是借机重新设计产品。
8. AI关键帧优先无文字；字幕建议后期完成，确保中文准确、与个人站现有排版语言一致。
9. 本文档仅为短视频提示词与关键帧方案，不代表已完成视频生成、性能测试或工程验证。
