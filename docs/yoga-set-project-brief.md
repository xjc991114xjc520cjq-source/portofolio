## 首款设计

内部工作名：弧序。公开名称待母版确认。

低强度瑜伽与普拉提使用方向；运动内衣与高腰九分裤两件套。深墨蓝细密哑光针织，钢蓝窄嵌边。圆角方领、宽肩带、弧形下围与双弧腰头形成系列语言；后背单一横向椭圆开口。不设计多重绑带、深V后腰、提臀抽褶或显眼Logo。

所有尺寸描述均为视觉设计起点，不是服装纸样或生产规格。支撑等级、抗起球、透气、不透、面料成分等需要实物与测试支持，不能从生图推断。

## 制作顺序与文件

先执行 work/deliverables/yoga-set-gemini/01.txt。确认前片、腰头、颜色、面料及人物后，将合格图作为参考执行02；正背一致后再做03细节和04基础侧弯。每个TXT只有一段可独立复制的图像指令，编号、项目定位和营销判断不进入图中。

01：4:5正面；02：4:5背面；03：1:1结构细节；04：4:5基础侧弯。

02的后背结构为首轮新增设计，须与01肩带及下围衔接核对；生成模型不能保证工程可行性。没有通过01时不批量扩展场景或换色。

## 质量审核

- 肩带、下围、腰头、嵌边、背部开口数量与位置一致。
- 同一人的脸与身体比例一致；无夸张腰臀或拉长腿部。
- 哑光针织不是皮革、乳胶或塑料；真实轻微褶皱允许存在。
- 正背与全身动作不截断头、手、脚；细节图有意局部取景。
- 手脚与关节正确，布料无穿模；不以AI静帧宣称运动性能。
- 无文字、Logo、水印、图标、价格、白边或拼图。
